# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

This is a beginner HTML learning project. Files are plain `.html` with no build system, no CSS framework, and no JavaScript — just standard HTML opened directly in a browser.

## Files

- `index.html` — personal intro page (Korean), no CSS
- `airport_vocabulary.html` — airport English vocabulary sheet organized by situation, using `<table border="1">` for layout, no CSS

## Conventions

- Language: Korean UI text and comments; English for vocabulary content
- No CSS: styling is intentionally omitted; use only HTML attributes (e.g., `border="1"` on tables)
- Encoding: UTF-8, `lang="ko"` on `<html>`
- All pages are standalone files — no shared assets or linking between pages
